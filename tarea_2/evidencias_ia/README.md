# Evidencias de uso de IA (`evidencias_ia/`)

Capturas de pantalla **de toda la conversación** con Claude Code (Opus) usada para desarrollar la Tarea 2, numeradas en orden
cronológico: `01.png`, `02.png`, …

- La conversación muestra el proceso real: una primera versión con datos **simulados** fue revisada contra el enunciado y
  rehecha con corpus real, OCR/ASR ejecutados en local, referencias manuales y auditoría humana.
- Las capturas no contienen claves API, contraseñas ni datos personales (el diccionario de seudónimos nunca se muestra).
- Decisiones tomadas por la estudiante: esquema de referencias (manual + transcripción oficial de OpenSLR), OCR alternativo
  (Tesseract), LLM local (Qwen2.5), uso exclusivo de herramientas gratuitas, transcripción manual de 10 documentos y 5 entrevistas
  y auditoría humana de 20 extracciones del LLM.
